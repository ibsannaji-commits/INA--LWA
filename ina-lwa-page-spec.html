Course and learning flow

Course detail (/course/course-name)

Title, short description, ⭐ 4.8, 1,250 students, 12 lessons, 4 hours, certificate included, instructor. Buttons: Enroll Now · Add to Wishlist · Share. Curriculum: Module 01 Introduction (Lessons 1–3) · Module 02 Foundations (Lessons 4–5, Quiz) · Module 03 Application (Lesson 6, Assignment) · Final Assessment. Some lessons can be locked.

Lesson player

Course/lesson list beside video. Play/pause, progress, captions, speed, notes, resources. Buttons: Previous · Complete & Continue. Protect video against download.

Lesson progress

Complete lesson → lesson_progress = completed → next lesson unlocks → course progress updates.

Quiz, assignment, final exam

Quiz: question, options A–D, Submit Answer, e.g. 8/10, Pass: YES. Assignment: title, instructions, deadline, required file (PDF, DOCX, XLSX, image), Upload Assignment; instructor reviews, scores, gives feedback. Final exam: timer, pass score, attempt limit, randomization, auto-submit; pass mark 70%; retake only if policy allows.

Certificate center and /verify

List: program, issue date, ID, status; buttons View · Verify · Share. Public verify: enter ID (INA-LWA-2026-000001) → Verify Certificate → ✓ VERIFIED with student, program, issued year, ID, status VALID.

Checkout and payment

Checkout page

Total

Customer: full name, email, phone, country, payment method (Chapa, Telebirr, bank/payment methods the integration supports). Button: Pay & Enroll.

Payment workflow

Checkout›Create order›Gateway›Callback/Webhook›Server verification›Payment confirmed›Enrollment created›Access granted›Confirmation
Don't trust the callback alone: verify payment on the server. Relationship: User → Order → Order items → Payment → Verification → Enrollment → Access. This prevents fraud and duplicate enrollment.

Security and admin control

Must-have

  • HTTPS
  • Password hashing
  • MFA for admin
  • Role-based access
  • Rate limiting
  • Input validation
  • Secure file upload
  • Audit logs
  • Backup
  • Session management
  • Payment verification
  • Webhook signature verification
  • Admin login protection

Least-privilege admin roles

Finance: payments, refunds, payouts · Academic: courses, exams, certificates · Marketing: campaigns, coupons, content · Support: users, tickets · Super Admin: everything.

Audit log

Every action records who, what, when, from where, before, after. Example: Admin X changed course price from 499 ETB to 699 ETB.
