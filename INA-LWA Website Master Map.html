Technology and protection

Stack (depends on team, cost and security)

Frontend Next.js/React, responsive, PWA · Backend Node.js/NestJS or Laravel, REST/GraphQL · PostgreSQL · object storage/CDN · secure session/JWT · protected video streaming · Ethiopian payment gateways · email, SMS, push · analytics.

Video security

No public MP4 links. Authenticated user → signed/protected video access.

Content protection

PDF/resources: user-specific access, download controls, watermark option, access expiration, copyright notice. Certificates: unique ID, QR, verification database.

Financial engine

Transaction ledger: order → payment → refund → revenue → instructor share → affiliate commission → platform revenue → payout. Double-entry accounting is not required, and can connect later.

Certificate verification /verify

Enter ID INA-LWA-2026-000125. Result: ✅ VERIFIED with student, program, score, instructor, issue date, ID and QR.
