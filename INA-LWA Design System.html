UI/UX rules

1. One page = one primary goal.
2. The CTA is clear.
3. Don't hide information.
4. Keep the payment flow short.
5. Students always know where they are and what's next.
6. Mobile is never second to desktop.

Hero rule

One strong headline, one supporting message, two CTAs, one strong visual. No long paragraphs, no five buttons, no heavy animation.

Responsive, accessibility, performance

Breakpoints
Mobile <768 (1 column) · Tablet 768–1024 (2) · Desktop 1024–1440 (3–4) · Large >1440
Accessibility
Keyboard navigation, alt text, contrast, readable fonts, focus states, form labels, captions. Clean Afaan Oromoo typography. Dark mode: Light / Dark / System.
Performance
Image optimization, lazy loading, CDN, video streaming, code splitting, caching, minified assets, database indexing. Fast on mobile internet.
